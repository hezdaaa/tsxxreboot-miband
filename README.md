## ✨ 技术展示

### 数据规模

| 指标 | 数值 |
|---|---|
| 原作 | 天使☆騒々 RE-BOOT!（柚子社，2023 发售，18+） |
| 剧本文件 | 123 个 `scriptData` 分块 |
| 全局页表 | **约 61,436 页** |
| 运行平台 | 小米手环快应用（watch，336×480 竖屏） |
| 打包产物 | 快应用 rpk |

### 功能特性

- **完整剧本**：全线文本 → 全局线性页表，逐页加载
- **分支与路线**：选项分支、flag 路线判定、多女主路线，含 **BAD END / END** 多结局
- **存档 / 读档**：多槽位断点存档，支持「从上次开始」
- **CG 鉴赏**：通关收集，画廊页（`cgs`）
- **流程图**：路线图快速跳转（`lct`）
- **章节跳转**：直接跳往任意章节
- **操作**：点击翻页、左滑回退、长按隐藏文本框、下滑呼出菜单、设置页

### 技术架构

```
原作 .xp3 资源
   │  ① 解包：GARbro / KrkrExtract / 剧本提取工具集
   ▼
剧本文本 + 图片素材
   │  ② 剧本提取：FreeMote（.ks.scn → 结构化数据）
   │  ③ 转换：剧本 JSON → 手环脚本格式（文本/背景/立绘/CG/特效字段）
   │  ④ 合并：按 500 页/块 合并为全局线性页表 scriptData*.txt
   │  ⑤ 分支配置：选项点 / 路线路由 / 跳转特判 / 结局（END / BAD END）
   ▼
快应用资源
   │  ⑥ 立绘合成：AutoCGAligner 对齐身体与表情差分
   │  ⑦ 资源处理：背景 / CG / SD 压缩、去重、裁剪
   ▼
src/ ──→ 小米手环快应用（rpk）
```

### 资源处理

| 工具 / 脚本 | 作用 |
|---|---|
| `提取转换/KRKR解包工具`（GARbro / KrkrExtract / FreeMoteViewer / KrKrDump 等） | 原作 XP3 封包解包、剧本反编译、立绘信息提取 |
| `批量处理/`（cgth / lh处理 / sd处理 等） | CG、立绘、SD 小人批量处理与去重 |
| `编辑器.py` | 图形化剧本编辑器（GalGameScriptEditor，黑色主题），实时预览与修正 |
| `其他/` | 图片压缩、旋转、裁切、重命名、文本批量处理等杂项工具 |

### 安装使用

1. 使用**小米手环快应用开发工具**打开 `src/` 目录。
2. 编译打包生成 `.rpk`。
3. 通过配套工具安装到小米手环并启动。

> 需要正版原作数据支持（解包出的剧本与图片）。**未购买正版请勿使用。**
